# Атом от А до Я

Учебный сайт по атомной энергетике для подготовки к экзамену: 14 глав с большими текстами
(от строения ядра до АЭС, безопасности, топливного цикла и атомной отрасли Казахстана),
формулы с примерами расчёта, интерактивные изометрические модели, тесты после каждой главы,
тренажёр со случайными вопросами, экзаменационные билеты, глоссарий, лист формул и литература.

Готовый сайт лежит в `docs/` — это статические файлы, их можно открыть локально или включить
GitHub Pages (Settings → Pages → Deploy from branch → `/docs`).

## Сборка

```bash
node build.mjs
```

- `content/NN-slug.html` — главы (формат описан в `content/SPEC.md`);
- `figures/*.mjs` — интерактивные фигуры: каждая — прибор на верстаке, числа в углу считаются
  той же моделью, что двигает детали (энергия связи, распад, защита, цепная реакция,
  управление реактором с точечной кинетикой, твэл и ТВС, энергоблок ВВЭР-1000);
- `src/` — стили, клиентский скрипт и лист формул;
- `kit/` — изометрический набор [Anatomy](https://github.com/wheresryan22/anatomy) (MIT);
- `vendor/katex/` — KaTeX 0.16.9 (MIT) для формул.

Проверка одной фигуры: `node scripts/figtest.mjs core` пишет отдельную страницу с фигурой.
