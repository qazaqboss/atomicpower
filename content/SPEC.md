# Спецификация файла главы

Каждая глава — один файл `content/NN-slug.html` (UTF-8). Это **фрагмент**, не полный документ: без `<html>`, `<head>`, `<body>`, без `<style>` и `<script>`. Сборщик (`build.mjs`) разбирает файл регулярными выражениями, поэтому структуру нужно соблюдать **точно**.

Язык — русский, научно-учебный стиль уровня вуза (бакалавриат «Ядерная энергетика и теплофизика» / «Ядерные физика и технологии»). Цель — чтобы по сайту можно было подготовиться и сдать экзамен. Тексты большие и связные: объяснять «почему», а не только «что»; давать числа, единицы, порядки величин, примеры расчёта. Все числа должны быть реальными и проверяемыми (справочные данные МАГАТЭ, IAEA PRIS, NNDC/ENDF, учебники). Если не уверен в цифре — не пиши её.

## Что можно использовать внутри `<section class="body">`

- `<h2 id="латиница-через-дефис">` — разделы (6–10 штук на главу), `<h3>` — подразделы. Только у `h2` обязателен `id`.
- `<p>`, `<ul>`, `<ol>`, `<strong>`, `<em>`, `<sup>`, `<sub>`.
- Формулы — LaTeX для KaTeX: строчные `\( E = mc^2 \)`, выносные `\[ N(t) = N_0 e^{-\lambda t} \]`. Не использовать `$`.
- Таблицы: `<div class="table"><table><thead>…</thead><tbody>…</tbody></table></div>`.
- Определение: `<div class="def"><b>Термин</b> — определение.</div>`
- Важное замечание: `<div class="note">…</div>`
- Пример/задача с решением: `<div class="example"><b>Пример.</b> условие… <br>Решение: …</div>`
- Исторический факт: `<div class="history">…</div>`
- Место для интерактивной фигуры (только если указано в задании главы): `<!--FIG:имя-->` отдельной строкой.
- Ссылка на другую главу: `<a href="NN-slug.html">название</a>`.

Не используй: картинки, iframe, inline-style, классы кроме перечисленных, эмодзи.

## Объём

Тело главы — **3500–5500 слов** (это большая глава). Каждый `h2`-раздел — несколько абзацев плюс, где уместно, формула, таблица, пример расчёта.
